# AI Resume Analyzer

## Project Overview

AI Resume Analyzer is an AI-powered web application that analyzes resumes and provides ATS (Applicant Tracking System) based feedback. The application helps users understand their resume strengths, missing skills, weaknesses, and improvement suggestions to increase their chances of selection.

## Features

* Upload resume in PDF format
* Extract resume text automatically
* AI-based resume analysis using Groq API
* ATS score generation
* Identify missing skills
* Display resume strengths and weaknesses
* Provide improvement suggestions
* Save previous analysis history
* Dashboard with analysis statistics
* Download AI analysis report as PDF
* Responsive design for desktop and mobile devices

## Installation and Setup

1. Clone the repository:

```
git clone your-github-repository-link
```

2. Navigate to project folder:

```
cd AI-Resume-Analyzer
```

3. Install dependencies:

```
npm install
```

4. Create a `.env` file and add your Groq API key:

```
VITE_GROQ_API_KEY=your_api_key_here
```

5. Start the development server:

```
npm run dev
```
